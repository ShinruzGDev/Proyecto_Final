Este juego se supone que incluía mecanicas de planeo, checkpoint, y jumpads
una aventura de decenso donde el personaje tenía que bajar a través de obstaculos para llegar a la llave que termina el juego.
De las caracteristicas logradas a desarrollar se pudo implementar el planeo, la cual es clave para la sucesión del juego,
también se implementaron los jumpads en colisión con su respectivo tag "BouncePad" el cual se podía asignar a cualquier gameobject.

Es sobre una persona hibirda con caracteristicas de ave, basado en plataformas flotantes del universo narrativo Kyneastis.

De ante mano le pedimos disculpas por el resultado que le entregamos.
